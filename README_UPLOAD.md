# Eliminacode Server Windows v1

Caricare nel repository mantenendo esattamente questi percorsi:

- apps/server-windows/package.json
- apps/server-windows/main.cjs
- apps/server-windows/server.cjs
- apps/server-windows/public/admin.html
- apps/server-windows/public/claim.html
- .github/workflows/build-server-windows.yml

Dopo il commit: GitHub > Actions > Build Eliminacode Server Windows > Run workflow.

Il server locale parte sulla porta 8787 e usa SQLite locale.
