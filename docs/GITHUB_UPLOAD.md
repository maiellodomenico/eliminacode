# Caricamento iniziale su GitHub

Il contenuto di questa cartella deve essere caricato direttamente nella radice del repository `eliminacode`.

La radice corretta deve mostrare immediatamente:

- `.github`
- `apps`
- `docs`
- `supabase`
- `.gitignore`
- `README.md`

Non caricare la cartella contenitore `eliminacode_github_definitivo` come sottocartella del repository.

Se nel repository esiste già `github-package/`, può essere eliminata dopo che questo nuovo contenuto è stato caricato correttamente.
